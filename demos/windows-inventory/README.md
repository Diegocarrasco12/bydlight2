# Bydlight Inventario - Demo

Aplicación de escritorio Windows (WinForms, .NET 8) que muestra capacidades de Bydlight.
Es una demo con **datos ficticios**: sin red, sin base de datos y sin acceso a archivos.

- Ejecutar: `dotnet run -c Release`
- Captura: `dotnet run -c Release -- --screenshot ruta.png`
